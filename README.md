# ✅ Task Manager – To-Do List Web Application

Task Manager is a simple and interactive web application built using **HTML, CSS, and JavaScript**. It allows users to add, complete, and remove tasks while also providing a contact form with client-side validation.

## 🚀 Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Remove tasks
* ⌨️ Add tasks using JavaScript
* 📝 Contact form
* ✔️ Form validation
* ⚠️ Displays validation error messages
* 🎉 Displays successful form submission message
* 📱 Responsive design
* 🎨 Clean and user-friendly interface
* 🔗 Navigation between different sections

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6)** – Task management and form validation
* **DOM Manipulation** – Dynamically adding and removing tasks
* **Event Listeners** – Handling user interactions

## 📋 How to Use

### Task Manager

1. Enter a task in the input field.
2. Click **Add Task**.
3. The task will appear in the To-Do List.
4. Mark the task as completed when finished.
5. Remove tasks when they are no longer needed.

### Contact Form

1. Enter your name.
2. Enter your email address.
3. Enter your message.
4. Click **Submit**.
5. JavaScript validates the entered information.
6. Error messages are displayed if the input is invalid.
